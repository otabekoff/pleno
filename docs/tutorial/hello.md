# Hello, Pleno

Welcome! This tutorial teaches Pleno in fifteen short lessons. Each one explains an idea on this side and gives you code to edit and run on the other. Everything runs in your browser.

Here is a complete Pleno program:

```pleno
print("Hello, Pleno!");
```

`print` writes its arguments to the output, separated by spaces. Statements end with a semicolon.

Press **Run** (or <kbd>Ctrl</kbd> + <kbd>Enter</kbd>) to try it.
