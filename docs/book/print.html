Pleno Language

Pleno Programming Language

Complete Language Specification v1.0

File Extension: .pln
Paradigms: Object-Oriented, Functional, Procedural, Mixed
Typing: Dynamic with optional static typing and gradual typing support
Design Philosophy: Clarity, Safety, Expressiveness, Modern Best Practices

Overview

String Encoding Decision

Pleno uses UTF-8 for all string literals and runtime strings.

Key points:

  • UTF-8 is the 2026+ industry standard across tools, platforms, and APIs.
  • ASCII remains 1 byte per char, keeping source code compact.
  • Full Unicode support is preserved for international text and emoji.

String indexing defaults to Unicode scalar values for safety. Byte-level access is provided via explicit APIs.

Bytecode VM Design (Register-Based)

Pleno will use a register-based bytecode VM from the start. This choice is performance-oriented and aligns with the goal of being faster than Python while remaining dynamic. A register VM yields fewer instructions, fewer memory push/pop operations, and a cleaner path to JIT later.

High-Level Pipeline

Source (.pln)
  -> Lexer -> Parser -> AST
  -> Compiler -> Bytecode (Chunk)
  -> VM -> Execute

Instruction Set (v0)

Design goals:

  • Keep opcodes minimal and orthogonal.
  • Use fixed-width instruction encoding for fast decoding.
  • Keep register count bounded per function for locality.

Encoding

Each instruction is 4 bytes:

[Opcode: u8][A: u8][B: u8][C: u8]
  • A is destination register.
  • B, C are source registers or immediate indices (depending on opcode).

Core Opcodes

Register and Constants

  • Move (R[A] = R[B])
  • LoadConst (R[A] = Constants[B])
  • LoadNull (R[A] = null)
  • LoadTrue (R[A] = true)
  • LoadFalse (R[A] = false)

Arithmetic

  • Add Sub Mul Div Mod
  • Neg

Comparison

  • Eq Ne Lt Le Gt Ge

Logical

  • Not
  • And Or (compiled via jumps for short-circuit)

Control Flow

  • Jump offset
  • JumpIf offset (if R[A] then PC += offset)
  • JumpIfNot offset (if !R[A] then PC += offset)

Variables

  • GetGlobal (R[A] = Globals[Constants[B]])
  • SetGlobal (Globals[Constants[B]] = R[A])

Calls

  • Call (R[A] = RB)
  • Return (return R[A])
  • Closure (R[A] = closure(proto[B]))

Objects and Collections

  • GetProperty (R[A] = R[B][Constants[C]])
  • SetProperty (R[B][Constants[C]] = R[A])
  • GetIndex (R[A] = R[B][R[C]])
  • SetIndex (R[B][R[C]] = R[A])
  • NewArray (R[A] = [])
  • NewMap (R[A] = {})
  • ArrayAppend (R[A].push(R[B]))

Advanced

  • Import (R[A] = import(Constants[B]))
  • Throw (throw R[A])
  • TypeOf (R[A] = typeof(R[B]))
  • Is (R[A] = R[B] is Type[C])

Fast Paths (Optional v0.1)

  • LoadInt (R[A] = smallint(B))
  • AddInt (R[A] = R[B] + immediate)
  • SubInt (R[A] = R[B] - immediate)

Bytecode Structures

  • Chunk.code: Vec<Instruction>
  • Chunk.constants: Vec<Value>
  • Chunk.prototypes: Vec<Function>
  • Chunk.lines: Vec<u32>
  • Chunk.max_registers: usize

Compiler Guide

Register Allocation

  • Per function, allocate registers for locals and temporaries.
  • Keep registers small (<= 256) for compact encoding.
  • Free temporaries after use to reduce pressure.

Expressions

  • Literal: LoadConst into a fresh register.
  • Binary: compile left into R1, right into R2, emit opcode into R3.
  • Unary: compile operand into R1, emit opcode into R2.

Variables

  • let x = expr -> compile expr into Rn, bind local to Rn.
  • x = expr -> compile expr into Rn, emit store to local/global slot.

If/Else

  1. Compile condition into Rn.
  2. JumpIfNot to else label.
  3. Compile then block.
  4. Jump to end label.
  5. Patch else label, compile else block.

While / For

  • Track loop start and end labels.
  • JumpIfNot exits loop.
  • Jump/Loop (negative offset) for continue.

Functions + Calls

  • Each function produces a Chunk with its own register file size.
  • Call uses a base register and contiguous args.

Closures

  • Capture locals into upvalues in the compiler.
  • Emit Closure with upvalue descriptors.
  • Runtime resolves captures to shared cells.

OOP

  • class compiles to class object in constants.
  • obj.field -> GetProperty name_idx.
  • obj.field = expr -> compile expr, SetProperty.
  • obj.method(a,b) -> Invoke (optional), or GetProperty + Call.

Pattern Matching

Compile match to a cascade of tests and jumps.

  • Evaluate match value once into a temp register.
  • For each case: emit test, JumpIfNot to next.
  • Guard expressions compiled into boolean checks.
  • Default case is the final fall-through.

VM Implementation Guide

VM State

  • registers: Vec<Value>
  • frames: Vec<CallFrame>
  • globals: HashMap<String, Value>

Call Frame

  • closure: Rc<Closure>
  • ip: usize
  • base: usize (register base for frame)

Execution Loop

  • Fetch Instruction at ip and increment.
  • Decode opcode, a, b, c.
  • Dispatch via match.
  • For errors, return RuntimeError (no panics).

Value Model (Dynamic)

Start with a tagged enum; move to NaN boxing later if needed.

Value::Null | Bool | Int | Float | String | Array | Map | Set | Function | Closure | Object | Class

Garbage Collection Design

v0: Tracing mark-sweep

  • Heap stores arrays, maps, strings, functions, objects.
  • Roots:
    • Register file
    • Globals
    • Call frames (closures, upvalues)
  • Mark: traverse references and mark reachable.
  • Sweep: free unmarked objects.

Future: Generational GC

  • Young gen for short-lived values.
  • Old gen for long-lived values.
  • Requires write barriers.

Why Register VM (Best Now)

  • Fewer instructions per program.
  • Better cache locality vs. stack VM.
  • Easier path to JIT and inline caching.

We can start with register VM and still add optimizations incrementally:

  • Inline caches for property access
  • NaN boxing for compact values
  • Specialized opcodes for common fast paths

5. CI/CD & Release Automation

GitHub Actions Workflow

# .github/workflows/release.yml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  build:
    strategy:
      matrix:
        include:
          - os: ubuntu-latest
            target: x86_64-unknown-linux-gnu
          - os: ubuntu-latest
            target: aarch64-unknown-linux-gnu
          - os: macos-latest
            target: x86_64-apple-darwin
          - os: macos-latest
            target: aarch64-apple-darwin
          - os: windows-latest
            target: x86_64-pc-windows-msvc

    runs-on: ${{ matrix.os }}

    steps:
      - uses: actions/checkout@v3
      
      - name: Install Rust
        uses: actions-rs/toolchain@v1
        with:
          toolchain: stable
          target: ${{ matrix.target }}
      
      - name: Build
        run: cargo build --release --target ${{ matrix.target }}
      
      - name: Package
        run: |
          mkdir -p dist
          cp target/${{ matrix.target }}/release/pleno dist/
          cp -r stdlib dist/
          tar czf pleno-${{ matrix.target }}.tar.gz -C dist .
      
      - name: Upload Release Asset
        uses: actions/upload-release-asset@v1
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        with:
          upload_url: ${{ steps.create_release.outputs.upload_url }}
          asset_path: ./pleno-${{ matrix.target }}.tar.gz
          asset_name: pleno-${{ matrix.target }}.tar.gz
          asset_content_type: application/gzip

  publish-crates-io:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Publish to crates.io
        run: cargo publish --token ${{ secrets.CARGO_TOKEN }}

  publish-docker:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Build and push Docker image
        run: |
          docker build -t pleno/pleno:${{ github.ref_name }} .
          docker push pleno/pleno:${{ github.ref_name }}

Variables (mutable)

Constants (truly immutable)

// Constants cannot be reassigned - enforced at runtime
const list = [1, 2, 3];
// list = [4, 5, 6];  // ERROR: Cannot reassign constant
// list.push(4);      // ERROR: Cannot mutate constant value

Deep Immutability

const deep obj = {
    name: "Alice",
    scores: [95, 87, 92]
};
// obj.name = "Bob";           // ERROR
// obj.scores.push(88);         // ERROR
// obj.scores[0] = 100;         // ERROR

1.3 Type System

Primitive Types

Int      // 64-bit signed integer
Float    // 64-bit floating point
String   // UTF-8 string
Bool     // true or false
Char     // Single Unicode character
Null     // null type
Void     // No return value
Any      // Dynamic type (opt-out of type checking)

Type Annotations

let age: Int = 25;
let price: Float = 99.99;
let active: Bool = true;
let data: Any = "flexible";

// Function with type annotations
fn calculate(x: Int, y: Float): Float {
    return x * y;
}

Type Inference

let count = 42;              // Inferred as Int
let ratio = 3.14;            // Inferred as Float
let message = "Hello";       // Inferred as String
let mixed = null;            // Inferred as Null (can be reassigned)

Union Types

let result: Int | String = 42;
result = "error";  // Valid

fn process(value: Int | Float | String): String {
    return value.toString();
}

Optional Types

let optional: Int? = null;   // Can be Int or null
let username: String? = "alice";

// Safe navigation operator
let length = username?.length;  // Returns Int? (null if username is null)

// Null coalescing
let displayName = username ?? "Guest";

// Forced unwrap (runtime error if null)
let definite = username!;  // Use with caution

Type Guards

fn processValue(val: Int | String) {
    if (val is Int) {
        // val is narrowed to Int here
        print(val * 2);
    } else {
        // val is narrowed to String here
        print(val.toUpperCase());
    }
}

14.3 Operator Overloading

class Vector {
    private x: Float;
    private y: Float;
    
    constructor(x: Float, y: Float) {
        this.x = x;
        this.y = y;
    }
    
    // Overload + operator
    operator +(other: Vector): Vector {
        return Vector(this.x + other.x, this.y + other.y);
    }
    
    // Overload * operator (scalar multiplication)
    operator *(scalar: Float): Vector {
        return Vector(this.x * scalar, this.y * scalar);
    }
    
    // Overload == operator
    operator ==(other: Vector): Bool {
        return this.x == other.x && this.y == other.y;
    }
    
    // Overload [] operator
    operator [](index: Int): Float {
        match (index) {
            case 0 => return this.x,
            case 1 => return this.y,
            case _ => throw Error("Index out of bounds")
        }
    }
}

let v1 = Vector(1.0, 2.0);
let v2 = Vector(3.0, 4.0);
let v3 = v1 + v2;          // Vector(4.0, 6.0)
let v4 = v1 * 2.0;         // Vector(2.0, 4.0)
print(v1 == v2);           // false
print(v1[0]);              // 1.0

18.3 Todo CLI Application

import { File } from "std:io";
import { JSON } from "std:json";

class TodoManager {
    private todos: Array<Todo> = [];
    private file: String = "todos.json";
    
    constructor() {
        this.load();
    }
    
    fn add(title: String) {
        let todo = Todo(title);
        this.todos.push(todo);
        this.save();
        print("Added: " + title);
    }
    
    fn list() {
        if (this.todos.isEmpty()) {
            print("No todos yet!");
            return;
        }
        
        for (index, todo in this.todos) {
            let status = todo.completed ? "[✓]" : "[ ]";
            print(`${index + 1}. ${status} ${todo.title}`);
        }
    }
    
    fn complete(index: Int) {
        if (index >= 0 && index < this.todos.length) {
            this.todos[index].completed = true;
            this.save();
            print("Completed: " + this.todos[index].title);
        }
    }
    
    fn remove(index: Int) {
        if (index >= 0 && index < this.todos.length) {
            let removed = this.todos.remove(index);
            this.save();
            print("Removed: " + removed.title);
        }
    }
    
    private fn save() {
        File.write(this.file, JSON.stringify(this.todos));
    }
    
    private fn load() {
        if (File.exists(this.file)) {
            let content = File.read(this.file);
            this.todos = JSON.parse(content);
        }
    }
}

class Todo {
    public title: String;
    public completed: Bool = false;
    
    constructor(title: String) {
        this.title = title;
    }
}

fn main(args: String[]) {
    let manager = TodoManager();
    
    if (args.length == 0) {
        print("Usage: todo [add|list|complete|remove] ...");
        return;
    }
    
    match (args[0]) {
        case "add" => {
            if (args.length > 1) {
                manager.add(args[1..].join(" "));
            }
        },
        case "list" => manager.list(),
        case "complete" => {
            if (args.length > 1) {
                manager.complete(Int.parse(args[1]) - 1);
            }
        },
        case "remove" => {
            if (args.length > 1) {
                manager.remove(Int.parse(args[1]) - 1);
            }
        },
        case _ => print("Unknown command")
    }
}

Conclusion

Conclusion

Pleno is designed to be:

  • Easy to learn: Familiar syntax, clear semantics
  • Safe by default: Strong typing, real encapsulation, memory safety
  • Powerful: OOP, functional, and procedural paradigms
  • Modern: Async/await, pattern matching, generics
  • Practical: Great standard library, package manager, tooling

This specification provides a complete foundation for a modern programming language suitable for 2026 and beyond.
