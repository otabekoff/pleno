# Getting help

- **Documentation:** the [Pleno docs](https://pleno.mohirlab.uz/) cover the language, the standard library and the tools.
- **Questions:** ask in [Discussions](https://github.com/otabekoff/pleno/discussions).
- **Bugs, documentation problems and feature requests:** search the [issues](https://github.com/otabekoff/pleno/issues), then [open a new one](https://github.com/otabekoff/pleno/issues/new/choose) with the form that fits. For a bug, the form asks for the Pleno version, your operating system, and the smallest program that shows the problem.
- **Security problems:** do not open a public issue. Report them privately as described in [SECURITY.md](SECURITY.md).

Pleno is maintained by one person in his own time, so answers can take a few days.
