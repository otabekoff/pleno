# Getting help

- **Documentation:** the [Pleno docs](https://pleno.mohirlab.uz/) cover the language, the standard library and the tools.
- **Questions and bugs:** search the [issues](https://github.com/otabekoff/pleno/issues), then open a new one. For a bug, include the Pleno version (`pleno --version`), your operating system, and the smallest program that shows the problem.
- **Security problems:** do not open a public issue. Report them privately as described in [SECURITY.md](SECURITY.md).

Pleno is maintained by one person in their own time, so answers can take a few days.
