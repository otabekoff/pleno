# Welcome to Pleno!

Pleno is a modern, type-safe, and dynamic programming language designed for clarity and performance.

The Pleno extension provides a rich development experience including:

- **IntelliSense**: Smart completions, hover info, and signature help.
- **Diagnostics**: Real-time error and lint reporting.
- **Testing**: Native integration with the VSCode Test Explorer.
- **Project Management**: Built-in explorer for modules and scripts.

Get started by following the steps in this guide!
