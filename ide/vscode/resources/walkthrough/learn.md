# Learn the language

The documentation at [pleno.mohirlab.uz](https://pleno.mohirlab.uz/) has:

- an interactive [tutorial](https://pleno.mohirlab.uz/tutorial/),
- the [guide](https://pleno.mohirlab.uz/guide/getting-started), from installation to packages
  and testing,
- the [language reference](https://pleno.mohirlab.uz/specs/) and the
  [standard library](https://pleno.mohirlab.uz/stdlib/),
- a [playground](https://pleno.mohirlab.uz/playground) that runs Pleno in the browser.
